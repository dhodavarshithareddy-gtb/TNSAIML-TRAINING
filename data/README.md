# Dataset instructions

Place the Pima Indians Diabetes CSV in this folder and name it:

`diabetes.csv`

The expected header is:

```csv
Pregnancies,Glucose,BloodPressure,SkinThickness,Insulin,BMI,DiabetesPedigreeFunction,Age,Outcome
```

The training script can also try downloading the Pima dataset using `ucimlrepo` (dataset ID 228). This requires an internet connection.

Dataset page: https://archive.ics.uci.edu/dataset/228/pima+indians+diabetes

The project does not include patient records. Do not add identifiable or private health information.
